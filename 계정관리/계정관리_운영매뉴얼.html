처음 오셨나요? 여기부터 읽으세요

이 업무는 회사에서 사용하는 모든 외부 온라인 서비스(ChatGPT, 이카운트, 하이웍스 등)의
계정, 비밀번호, 비용을 통합 관리하는 일입니다.

내가 하는 일은 뭔가요?
1
계정대장 관리
모든 서비스의 계정/비밀번호/비용을 Excel로 관리합니다
▼

계정대장은 이 업무의 핵심 파일입니다. 회사가 사용하는 모든 외부 서비스의 계정 정보가 이 Excel 파일 하나에 들어있습니다.

파일 위치: 공유 드라이브 → 경영관리팀 → 외부서비스_계정대장_YYMMDD.xlsx
2
신규 서비스 등록
부서에서 새 서비스를 신청하면 계정을 만들고 등록합니다
▼

각 팀에서 하이웍스 전자결재로 "온라인 서비스 이용 신청서"를 제출하면, 경영관리팀(나)이 확인하고 처리합니다.

핵심 흐름: 신청서 접수 → 등급 분류 → 품의서 작성 → 계정 생성 → 계정대장 등록 → 팀장에게 전달
3
비밀번호 주기적 변경
등급에 따라 분기/반기/연1회 비밀번호를 변경합니다
▼

2등급매출/출고/개인정보 관련반기 (6개월마다)
3등급그 외 서비스연 1회 (12개월마다)

비용 관리
매월 카드 명세서와 계정대장을 대조하고 비용을 확인합니다
▼

유료 서비스의 월 비용이 계정대장 J열에 기록되어 있습니다. 매월 법인카드(끝 4자리: 0817) 명세서와 대조하여 확인합니다.

비용 취합: 계정대장의 "비용 취합" 시트에서 분류별/등급별/부서별 비용 합계를 자동으로 확인할 수 있습니다.

일상 업무 타임라인

아래 주기에 따라 업무를 수행합니다.

매일
하이웍스 신청서 확인전자결재함 → "온라인 서비스 이용 신청서" 접수 여부 확인
신규 신청이 있으면 → [상황별 가이드] 탭 → "신규 서비스 요청" 참고
매주
비밀번호 상태 점검계정대장 S열 확인 → "곧만료" 또는 "변경필요" 서비스 파악
해당 서비스 → [상황별 가이드] 탭 → "비밀번호 변경" 참고
매월
비용 확인 + 미사용 서비스 점검
  1. 법인카드(0817) 이번 달 명세서 확인
  2. 계정대장 J열(월비용)과 명세서 금액 대조
  3. 차이가 있으면 원인 파악 (환율 변동, 요금제 변경 등)
  4. 사용하지 않는 서비스가 있는지 각 팀에 확인
  5. 계정대장 T열(월간점검)에 오늘 날짜 기록
분기 (3개월)
1등급 서비스 비밀번호 일괄 변경1등급 서비스 전체 비밀번호 변경 → 계정대장 G열/Q열 갱신 → 팀장 대면 전달
반기 (6개월)
2등급 서비스 비밀번호 일괄 변경2등급 서비스 전체 비밀번호 변경 → 1등급과 동일한 절차
연간 (12개월)
3등급 비밀번호 변경 + 전체 감사3등급 비밀번호 변경 + 전체 서비스 종합 감사
불필요한 서비스 해지, 등급 재분류, 비용 최적화 검토
점검 기록: 모든 점검 결과는 계정대장 T열(월간점검)에 날짜로 기록하고, 중요 변경 사항은 V열(비고)에 메모합니다.
신규 서비스 요청이 들어왔을 때
  1. 하이웍스 확인 — 전자결재함에서 "온라인 서비스 이용 신청서" 접수 확인
  2. 등급 분류 — 계정등급_분류도우미.html 열기 → 체크리스트 체크 → 1/2/3등급 자동 결정
  3. 품의서 작성 (유료만) — 하이웍스 → 작성하기 → "외부서비스 품의서" 선택 → 비용/사유 기재 → 신청서를 관련문서로 첨부 → 결재 올림
  4. 결재 승인 대기 — 승인될 때까지 대기. 반려 시 신청 부서에 사유 안내
  5. 계정 생성 — 해당 팀의 구글 계정으로 서비스 가입. 비밀번호는 사내 패턴 규칙 적용. 2차 인증 설정
  6. 법인카드 등록 (유료만) — 신청자가 담당자 자리로 방문 → 서비스 결제 화면까지 루트 세팅 → 담당자가 카드 직접 입력
  7. 계정대장 등록 — Excel 열기 → 새 행 추가 → A~W열 정보 입력 (등급B, 비밀번호G, 변경일Q 필수)
  8. 팀장에게 전달 — 서비스명, 가입 이메일, 비밀번호를 대면/구두로만 전달
주의: 비밀번호는 메신저/이메일로 절대 전송하지 않습니다. 법인카드 번호도 마찬가지입니다.
비밀번호 변경 주기가 왔을 때
  1. 대상 서비스 확인 — 계정대장 S열(비밀번호 상태)에서 "곧만료" 또는 "변경필요" 목록 추출
  2. 등급별 확인 — 1등급(분기) → 2등급(반기) → 3등급(연1회) 순서로 변경 대상 확인
  3. 서비스 로그인 — 현재 비밀번호(G열)로 로그인
  4. 비밀번호 변경 — 사내 패턴 규칙에 따라 새 비밀번호 설정
  5. 계정대장 업데이트 — G열(비밀번호) 갱신 → Q열(변경일) 오늘 날짜 → R열(다음변경일) 자동 계산 확인
  6. 팀장에게 전달 — 변경된 비밀번호를 대면/구두로만 전달
퇴사자가 발생했을 때 (긴급!)
당일 처리 필수! 퇴사자가 알고 있던 모든 서비스 비밀번호를 즉시 변경해야 합니다.
  1. 관련 서비스 파악 — 계정대장에서 퇴사자가 사용하던 서비스 목록 추출 (F열 사용부서 기준)
  2. 비밀번호 즉시 변경 — 해당 서비스 전체 비밀번호를 당일 내 변경
  3. 멤버 제거 — 좌석 기반 서비스의 경우 퇴사자 계정/멤버 삭제
  4. 계정대장 업데이트 — G열 갱신, Q열 변경일 기록, V열에 "퇴사자 OOO 비밀번호 변경" 기록
  5. 팀장에게 새 비밀번호 전달 — 대면 전달
리더로부터 잔디 요청을 받았을 때

리더들은 아래 3가지 양식으로 요청을 보냅니다:

양식받았을 때 할 일
비밀번호 변경 통보계정대장 G열(비밀번호), Q열(변경일) 업데이트
계정 해지 요청서비스 구독 취소 → 계정대장 P열(상태)을 "해지"로 변경 → V열에 사유 기록
계정 변경 요청요청 내용에 따라 해당 열 수정 (담당자 변경, 권한 변경 등)
  1. 양식 확인 — 어떤 양식인지, 필요 항목이 모두 기재되었는지 확인 (누락 시 재요청)
  2. 처리 — 위 표에 따라 처리
  3. 처리 완료 회신 — 잔디에서 요청자에게 "처리 완료" 회신
품의서를 작성해야 할 때
중요: 품의서는 경영관리팀 담당자(나)가 작성합니다. 부서가 아닙니다.
  1. 하이웍스 → 작성하기 → "외부서비스 품의서" 선택 (일반 품의서 아님!)
  2. 서비스명, 사용 목적, 사용 부서/인원 기재
  3. 월 비용(VAT 포함), 결제 방법(법인카드), 계약 기간 기재
  4. 온라인 서비스 이용 신청서를 관련문서로 첨부
  5. 결재 올림
계정관리는 회사의 모든 외부 서비스 접근 권한과 법인카드 정보를 다루는 업무입니다.

04
비밀번호 변경 주기 엄수
1등급 분기 / 2등급 반기 / 3등급 연1회 - 지연 시 보안 사고 위험
05
퇴사자 발생 시 즉시 비밀번호 변경
퇴사자가 알고 있던 모든 서비스 비밀번호를 당일 변경
06
관리 구글 계정 2차 인증 필수
service@, service02@ 모두 2단계 인증 활성화 유지
07
개인 계정으로 서비스 가입 금지
반드시 팀 구글 계정 또는 관리 전용 계정으로만 가입
법인카드 등록 절차 (대면 필수)
  1. 신청자 방문 — 신청서 승인 후, 신청자가 경영관리팀 담당자 자리로 직접 방문
  2. 루트 세팅 — 담당자 PC에서 해당 서비스의 카드 등록/결제 설정 화면까지 접속
  3. 카드 등록 — 담당자가 세팅된 화면에서 법인카드 정보를 직접 입력하여 처리 완료

* 이 절차는 카드 등록 경로 파악 시간을 줄이고, 법인카드 보안을 강화하기 위해 마련되었습니다.

  4. 결재선 설정 후 저장

FAQ / 자주 묻는 질문
무료 서비스도 신청해야 하나요?▼
네. 무료 서비스도 계정 관리가 필요합니다. 퇴사 시 계정 회수, 유료 전환 시 비용 관리를 위해 계정대장에 등록해야 합니다. 다만, 품의서는 유료 서비스에만 필요합니다.
개인 계정으로 이미 가입한 서비스는?▼
관리자 권한을 회사 계정(해당 팀 구글 계정 또는 service@gmail.com)으로 이전하거나, 새로 가입 후 데이터 마이그레이션합니다.
비밀번호를 분실한 경우?▼
1) 계정대장 G열에서 현재 비밀번호 확인 → 2) 안 되면 관리 이메일로 비밀번호 재설정 → 3) 재설정 후 계정대장 G열/Q열 갱신
서비스 해지 절차는?▼
1) 해지 요청 확인 → 2) 데이터 백업 필요 여부 확인 → 3) 구독 취소/계정 삭제 → 4) 계정대장 P열 "해지"로 변경 → 5) V열에 사유 기록. 삭제하지 말고 상태만 변경.
품의서는 누가 작성하나요?▼
경영관리팀 담당자(나)가 작성합니다. 부서에서 신청서를 올리면, 경영관리팀이 "외부서비스 품의서" 양식에 작성하여 결재를 올립니다.
등급 변경이 필요한 경우?▼
계정등급_분류도우미.html로 재분류 → 계정대장 B열 수정 → R열 자동 재계산. 등급 상향 시 즉시 비밀번호 변경 권장.
