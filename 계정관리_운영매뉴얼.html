업무 목적사내 외부 온라인 서비스의 계정을 체계적으로 관리하여, 무분별한 계정 생성을 방지하고 기업 정보 보안을 확보한다.

업무 배경

각 팀에서 개별적으로 온라인 서비스에 가입·사용하면서 다음과 같은 문제가 발생했습니다:

  • 보안 위험: 개인 명의 가입으로 퇴사 시 계정 회수 불가, 비밀번호 미관리
  • 비용 누수: 중복 서비스 가입, 미사용 유료 서비스 방치, 법인카드 임의 등록
  • 관리 공백: 누가 어떤 서비스를 사용하는지 파악 불가, 담당자 부재 시 접근 불가

이에 2026년 3월부터 경영관리팀에서 모든 온라인 서비스 계정을 일괄 생성·관리하는 체계를 도입하였습니다.

비밀번호 정기 변경 및 보안 등급 관리개인 PC/노트북 계정 관리

계정대장 유지 및 정기 점검소프트웨어 라이선스 (설치형) 관리
퇴직자 계정 회수 및 담당자 변경 처리도메인·호스팅 관리

시스템 소개

온라인 서비스 계정 관리는 넷폼알앤디에서 사용하는 모든 외부 온라인 서비스(클라우드, 업무도구, 디자인, 개발도구, AI도구 등)의 계정을 체계적으로 관리하기 위한 시스템입니다.

대외 명칭 안내: 대외적으로는 "온라인 서비스"라는 용어를 사용합니다. 내부 파일명에 "외부서비스"가 남아있을 수 있으나, 공지/안내/양식에서는 반드시 "온라인 서비스"를 사용하세요.

수식 설명

R열: 다음변경일 (자동 계산)

계산 로직: 비밀번호변경일(Q) + 등급별 변경주기
- 1등급: Q열 + 90일 (분기)
- 2등급: Q열 + 180일 (반기)
- 3등급: Q열 + 365일 (연1회)
Q열이 비어있으면 빈 값을 반환합니다.

S열: 비밀번호상태 (자동 계산)

계산 로직: 오늘 날짜와 다음변경일(R)을 비교
- 안전 : 다음변경일까지 30일 이상 남음
- 곧만료 : 다음변경일까지 30일 이내
- 변경필요 : 다음변경일이 지남

비용 취합 시트 연동

J열에 원화 숫자만 입력하면 비용 취합 시트에서 자동으로 합산합니다.

입력 예시: 월 15,000원이면 J열에 15000 입력 (원, 쉼표 없이 숫자만). 비용 취합 시트에서 분류별, 등급별 합산이 자동으로 이루어집니다.
4 신규 서비스 등록 절차
1
신청서 접수 사용 부서에서 하이웍스 전자결재로 "온라인 서비스 이용 신청서"를 제출합니다. 신청서에는 서비스명, 사용 목적, 예상 비용, 필요 인원 등이 포함됩니다.
2
검토 및 등급 분류 계정등급_분류도우미.html을 활용하여 서비스의 보안 등급을 분류합니다. 결재/금융 관련 여부, 개인정보 포함 여부 등을 기준으로 1~3등급을 결정합니다.
3
품의서 작성 (유료 서비스인 경우) 유료 서비스의 경우, 비용 근거를 포함한 품의서를 작성하여 결재를 받습니다. 계정관리_결재양식.html을 활용할 수 있습니다.
4
계정 생성 netformrnd.service@gmail.com으로 서비스에 가입합니다. 비밀번호는 사내 패턴 규칙을 따릅니다. 2차 인증이 가능한 서비스는 반드시 설정합니다.
5
계정대장 등록 Excel 계정대장의 메인 시트에 A~W열의 정보를 빠짐없이 입력합니다. 특히 등급(B), 비밀번호(G), 비밀번호변경일(Q)은 필수입니다.
6
팀장에게 전달 해당 부서 팀장에게 서비스명, 가입 이메일, 비밀번호 3가지만 전달합니다. 전달 시 보안에 유의하여 메신저 또는 구두로 전달합니다.
7
멤버 초대 (해당 시) 좌석(시트) 기반 서비스의 경우, 팀장 요청에 따라 사용자를 멤버로 초대합니다. 계정대장 비고(V)열에 초대 인원 수를 기록합니다.
등록 완료 확인: 계정대장에 모든 정보가 입력되고, 팀장에게 전달이 완료되면 등록 절차가 마무리됩니다. 대시보드에서 신규 등록 내역을 확인할 수 있습니다.
5 등급 체계 및 비밀번호 관리

3등급 체계

등급 색상 분류 기준 변경 주기

등급 분류가 애매한 경우: 계정등급_분류도우미.html에서 체크리스트를 통해 자동 분류하거나, 보수적으로(높은 등급으로) 분류합니다.

비밀번호 상태 확인 (S열)

상태 의미 조치
안전 다음 변경일까지 30일 이상 남음 조치 불필요
곧만료 다음 변경일까지 30일 이내 변경 일정 확인 및 준비
변경필요 다음 변경일이 지남 (연체 상태) 즉시 비밀번호 변경

비밀번호 변경 절차

1
대상 서비스 확인 계정대장 S열에서 "곧만료" 또는 "변경필요" 상태인 서비스를 확인합니다. 대시보드에서도 확인 가능합니다.
2
새 비밀번호 생성 사내 비밀번호 패턴 규칙에 따라 새 비밀번호를 생성합니다.
3
서비스 로그인 후 변경 해당 서비스에 접속하여 비밀번호를 변경합니다.
4
계정대장 갱신 G열(비밀번호)과 Q열(비밀번호변경일)을 업데이트합니다. R열과 S열은 자동으로 갱신됩니다.
5
팀장에게 재전달 변경된 비밀번호를 해당 부서 팀장에게 전달합니다.

12 FAQ / 자주 묻는 질문
개인 계정으로 이미 가입한 경우 어떻게 하나요? ▼
기존 개인 계정의 관리자 권한을 회사 관리 계정(netformrnd.service@gmail.com)으로 이전하거나, 새로 회사 계정으로 가입한 후 데이터를 마이그레이션합니다. 개인 계정은 서비스에서 제거하고, 계정대장에 회사 계정 정보를 등록합니다. 좌석 기반 서비스의 경우, 개인 이메일을 멤버로 초대하는 방식으로 전환할 수 있습니다.
무료 서비스도 신청해야 하나요? ▼
네, 무료 서비스도 신청 대상입니다. 무료 서비스라도 회사 업무에 사용하는 경우 계정 관리가 필요합니다. 담당자 퇴사 시 계정 회수, 보안 관리, 유료 전환 시 비용 관리 등을 위해 계정대장에 등록해야 합니다. 다만, 품의서는 유료 서비스에만 필요합니다.
비밀번호를 분실한 경우 어떻게 하나요? ▼
1단계: 계정대장 G열에서 현재 비밀번호를 확인합니다.
2단계: 계정대장에 기록된 비밀번호로도 로그인이 되지 않으면, 관리 이메일(netformrnd.service@gmail.com)로 비밀번호 재설정을 진행합니다.
3단계: 재설정 후 새 비밀번호를 계정대장 G열과 Q열에 갱신합니다.
2차 인증이 필요한 경우, I열에 기록된 인증번호 수신자에게 연락합니다.
서비스 해지 절차는 어떻게 되나요? ▼
1. 사용 부서의 해지 요청 확인 (전자결재 또는 메일)
2. 해당 서비스의 데이터 백업 필요 여부 확인
3. 서비스 구독 취소 또는 계정 삭제 진행
4. 계정대장 P열(상태)을 "해지"로 변경
5. 유료 서비스의 경우 다음 결제일 전에 해지 완료 확인
6. V열(비고)에 해지 사유 및 일시 기록
해지한 서비스는 계정대장에서 삭제하지 말고, 상태만 변경하여 이력을 보존합니다.
등급 변경이 필요한 경우 어떻게 하나요? ▼
서비스의 용도가 변경되거나 새로운 기능이 추가되어 등급 재분류가 필요한 경우:
1. 계정등급_분류도우미.html로 재분류 실행
2. 계정대장 B열(등급) 수정
3. 변경된 등급에 맞춰 R열(다음변경일)이 자동 재계산됨
4. 등급이 상향된 경우 즉시 비밀번호 변경 권장
연간 전체 감사 시 등급 재분류를 일괄적으로 진행하는 것이 효율적입니다.
