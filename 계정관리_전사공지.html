📢 외부 서비스 계정 관리 안내

경영관리팀 | 2026년 3월

안녕하세요, 경영관리팀입니다.
외부 서비스(SaaS) 계정의 체계적 관리를 위해 아래와 같이 안내드리오니,
업무에 참고하여 주시기 바랍니다.
1. 주요 변경사항
1
외부 서비스 신청은 전자결재로
업무에 필요한 외부 서비스(Notion, Figma, ChatGPT 등)는 하이웍스 전자결재「외부 서비스 이용 신청서」로 신청해 주세요.
2
계정은 경영관리팀에서 생성
승인 후 경영관리팀 전용계정으로 가입 처리하며, 로그인 정보는 사용부서 팀장에게 전달드립니다.
3
계정 정보는 팀장을 통해 공유
계정 ID·비밀번호는 팀장을 통해서만 팀 내 공유합니다. 외부 유출은 금지됩니다.
2. 신청 방법
하이웍스
전자결재
→
「외부 서비스
이용 신청서」
양식 선택
→
양식 작성
후 결재
→
승인 후
1~2일 내
계정 생성
3. 금지사항
아래 행위는 금지됩니다
  • 개인 명의(개인 이메일)로 외부 서비스 가입
  • 법인카드를 임의로 등록하여 결제
  • 전자결재 없이 외부 서비스 가입 또는 유료 전환
  • 계정 정보(ID, 비밀번호)를 외부에 공유
4. 기존 개인 명의 계정 안내
업무용으로 사용 중인 외부 서비스 중 개인 명의(개인 이메일)로 가입한 계정이 있으시면 경영관리팀으로 알려주세요.
확인 후 전용계정으로 순차 이관 진행하겠습니다. (이관 전까지는 기존 계정을 그대로 사용하시면 됩니다.)
5. 문의
외부 서비스 관련 문의사항은 경영관리팀으로 연락 부탁드립니다.
감사합니다.
