2. 관리자 페이지 - 탭 구성 (6개 탭)
탭 주요 기능 입력 항목 비고
차량목록 차량 등록/수정/삭제, 현황 요약 차량번호, 차종, 연식, 차대번호, 소유자, 등록일, 운행자, 소속부서, 용도, 상태 가장 먼저 등록! 다른 탭에 자동 반영

정비/점검 정비 이력 관리, 다음 점검일 알림 날짜, 유형(정기/엔진/타이어 등), 주행km, 정비소, 내용, 비용, 다음점검일 정비 유형 드롭다운 선택
비용관리 비용 등록, 카테고리별 분류 날짜, 카테고리(주유/보험/수리 등), 내용, 금액, 결제방법, 영수증 카테고리별 비용 합계 자동 계산
보험/등록 보험, 검사, 세금 관리 보험사, 증권번호, 보험종류, 보험기간, 보험료, 검사일, 세금납부 보험 만기일 관리 가능
통계/보고 차량 현황 차트, 월별 비용 추이, 보고서 - 월간보고서 Excel 다운로드 가능

5. 주의사항 & 활용 팁
⚠️ 주의사항
  • 차량 삭제 시 해당 차량의 모든 데이터 삭제됨
  • 편집잠금 중 다른 사용자 수정 불가 (5분 자동 해제)
  • Excel 가져오기 시 동일 차량번호는 자동 병합
  • 인터넷 연결 필수 (Firebase 클라우드)
💡 활용 팁
  • 통계/보고 탭에서 월간보고서 Excel 다운로드
  • 직원 링크를 카카오톡/문자로 공유하면 편리
  • 직원용 페이지를 홈화면에 추가하면 앱처럼 사용
  • 정기적으로 Excel 내보내기로 백업 권장
📱 홈화면 추가 방법
  • 아이폰: Safari 공유 → "홈 화면에 추가"
  • 안드로이드: Chrome 메뉴(⋮) → "홈 화면에 추가"
  • 홈화면 아이콘 터치 → 바로 입력 가능!
