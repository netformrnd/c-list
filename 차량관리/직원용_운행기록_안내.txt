========================================
  차량 운행기록 입력 안내
========================================

안녕하세요.
앞으로 차량 운행기록을 아래 링크에서
간편하게 입력해 주시기 바랍니다.


[운행기록 입력 링크]
https://netform-site.github.io/site-management/vehicle_driver.html


----------------------------------------
  사용방법 (30초면 끝!)
----------------------------------------

1. 위 링크 접속
2. 본인 이름 입력 (최초 1회만)
3. 본인 차량 터치
4. 출발지/도착지/목적 입력 (버튼 터치로 빠르게!)
5. 출발km / 도착km 입력
6. [저장하기] 터치 -> 끝!


----------------------------------------
  참고사항
----------------------------------------

- 핸드폰 홈화면에 바로가기 추가하면 편합니다
  (크롬 메뉴 > 홈 화면에 추가)

- 이름은 처음 한 번만 입력하면 자동 기억됩니다

- 출발지/도착지/목적은 자주 쓰는 항목이
  버튼으로 표시되어 터치만 하면 됩니다

- 출발km는 이전 도착km가 자동으로 채워집니다

- 주유한 경우 주유량/주유비도 같이 입력해 주세요

- 오늘 입력한 기록은 첫 화면에서 확인 가능합니다


----------------------------------------
  입력 시점
----------------------------------------

- 운행 완료 후 바로 입력 (권장)
- 또는 퇴근 전 한 번에 입력

매일 차량을 이용하시는 분은
운행 마칠 때마다 입력 부탁드립니다.


문의사항은 관리팀으로 연락 바랍니다.
감사합니다.
